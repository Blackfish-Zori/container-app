    About this app

    A minimal example of a single-page application.

    This whole app is one HTML file. There's no server, no page reloads, and no external libraries — just HTML for structure, CSS for style, and JavaScript for behavior.

    Three ideas make it a genuine SPA rather than a static page:

    Client-side routing. Clicking a nav link doesn't request a new page. JavaScript listens for hashchange events and swaps which <section> is visible.

    Shared state. Tasks live in a single JavaScript array. Every view reads from that same array, so adding a task on the Tasks screen instantly shows up in the Stats screen.

    Reactive rendering. Instead of manually editing the DOM in scattered places, one render() function rebuilds the visible view from current state whenever something changes.

    Built with plain HTML, CSS & JavaScript — no frameworks, no dependencies.
